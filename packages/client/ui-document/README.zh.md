# @deepseek-ai/dsh-client-ui-document

[English](README.md) | 中文

详情栏的文档半页，Codex 式：打开文件标签页（聚焦、逐页关闭与全部关闭）和其下的阅读器。项目目录树是框架最右栏（`frame.projectTree`，由 `ui-project` 占据），项目文件与聚焦文档因此并列显示——树位于最右端。阅读器展示聚焦标签页，可经查看 store 在源码模式（带行号、语法高亮的行）、阅读模式（`.md`/`.markdown` 路径渲染 Markdown，其余为纯文本）与渲染模式（`.html`/`.htm` 产物在沙箱 iframe 中渲染）间切换，模式跨刷新保留。浏览器侧注册进 `ui-conversation` 的 details 条目所声明的 `conversation.details.document` seat；从 cordis.yml 中移除本插件会让该 seat 留空，详情栏的文档标签页随即渲染为空，零开销。

阅读器内容由公开的会话快照（顶层节点列表加运行中调用列表）经一个纯函数 `deriveDocuments` 派生：已完成的 `read` 结果贡献其窗口行，`diff` 结果与运行中的 diff 调用贡献修改 hunk，`search` 路径结果贡献仅发现条目。按路径聚合时，阅读器展示最近一次读取窗口——或由整文件变更合成的创建文件全文——其后按顺序列出本会话的修改 hunk。条目按最近活动倒序排列，路径作为稳定次序的兜底。agent 运行期间面板自动跟随最新 read/edit；手动点击标签页会暂停跟随，直到下一轮次开始。面板的写入路径是 owner currency（`onOpen`/`onClose`）与声明的查看 store（阅读模式）；详情栏的标签页与 store 归 `ui-conversation` 所有。界面其他处的工具行与产出文件引用经 `ui-conversation` 的 `documentOpen` 服务打开到这里。

Node 侧是空的 apply（roster 行）；本插件不注册任何提示词段落、工具 schema 或会话事件。

## 模型体验

无，因为本包只是对已记录 read/edit/search 工具结果的浏览器侧只读投影，不注册任何模型可见内容。

#### KV Cache 影响

本包不新增系统提示词段落，也不新增请求内容，因此对 KV cache 复用没有任何影响。

## 已知限制与暂缓事项

- **阅读器内容源自工具活动而非文件系统**——浏览器读的是会话日志而非实时文件，因此最后一次读取之后的编辑以 diff 形式展示在读取内容下方，而不是重放进"当前文件"重建视图；未来若增加文件系统读取通道，可替换为实时源码视图。
- **持久化的文档标签页可能过期**——打开的标签页跨刷新保留，而条目只覆盖已加载窗口；过期标签页会在阅读器中呈现"不可用"提示，而不会打开任何内容。
- **路径身份区分大小写**——条目以工具调用使用的路径拼写为键，因此在 Windows 上以大小写混用拼写引用的同一文件会显示为多个标签页。归一化大小写会猜错区分大小写的文件系统；调用方应始终引用同一种拼写。
