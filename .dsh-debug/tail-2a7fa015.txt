ASSISTANT: 先直接回答你的两个问题：

## 1️⃣ 固化后能 git 吗？——能

固化成正式插件包后，它就是仓库里的普通代码（host 包 + client 包 + bundle 注册行），和你的目录树/文档阅读功能一样走 commit → push Gitee。

## 2️⃣ office 环境 gitee pull 能拿到带插件的版本吗？——能，而且是"永久版"

office 机器只需要：

```sh
git pull
pnpm install && pnpm run build
pnpm dsh web
```

插件就**内建在 Web UI 里**了，重启不丢、不需要每次挂载——这正是动态插件做不到、正式插件包能做的。唯一仍要手动做的是**凭证**（`.credentials.yaml` 里放 API Key + 平台令牌，每台机器各自配置）。
